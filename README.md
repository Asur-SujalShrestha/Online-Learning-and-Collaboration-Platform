**📚 Online Learning and Collaboration Platform**

An online learning and collaboration platform built with ReactJS, Spring Boot, and PostgreSQL that enables students, teachers, and admins to learn, collaborate, and communicate seamlessly.

**🚀 Features**

**👤 User Roles**

**Admin**

- Manage organizations and users

- Assign and update user roles

- View system dashboard

**Teacher**

- Create and share teaching content

- Post blogs, opinions, and resources

- Assign and review assignments

- Create groups for collaboration

**Student**

- Access learning content

- Submit assignments

- Post and collaborate in groups

- Participate in real-time chat and discussions

**💬 Collaboration**

- Real-time Chat (1-1 and group chat)

- Group Creation (teachers & admins can create groups, invite members)

- Video Conferencing for online classes and meetings

**📂 Learning & Assignments**

- Post teaching materials (text, images, files)

- Students can submit assignments online

- Teachers can review and provide feedback

**📊 Dashboard**

- View statistics about users, projects, milestones, and tasks

- Data visualization with interactive charts

**🛠️ Tech Stack**

- Frontend: ReactJS, Vite, TailwindCSS / CSS
- Backend: Java Spring Boot (REST APIs, WebSocket)
- Database: PostgreSQL
- Authentication: JWT & Role-Based Access Control
- Video Conferencing: 100ms.live Integration
- Deployment: (Optional: Docker, GitHub Pages, etc.)


**⚙️ Installation & Setup**

**🔧 Prerequisites**

- Node.js & npm

- Java 17+

- PostgreSQL

**🔹 Clone the Repository**

- git clone https://github.com/your-username/online-learning-collaboration.git

- cd online-learning-collaboration

**🔹 Backend Setup (Spring Boot)**

- cd backend

- ./mvnw spring-boot:run


- Configure application.properties with your PostgreSQL credentials.

**🔹 Frontend Setup (ReactJS + Vite)**

- cd frontend
- npm install
- npm run dev


**🗄️ Database Schema**

- user: stores user details

- organization: manages institutions

- project, milestone, task: collaboration & tracking

- group & chat: real-time communication

- assignment & submission: learning workflow

- post, likes, comments: social engagements
